# AdventureWorks2012 SQL Data Analysis Project

## 1. Project Overview
This project focuses on analysing business data using SQL Server and the AdventureWorks2012 sample database. The project demonstrates practical SQL skills through customer and sales data analysis.

## 2. Project Objectives
- Retrieve and analyse business data using SQL queries.
- Perform customer and sales-related analysis.
- Calculate total sales and summarize sales information.
- Organize and interpret data using SQL functions.

## 3. Tools and Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- AdventureWorks2012 Sample Database

## 4. SQL Concepts Used
- SELECT statements
- WHERE conditions
- Aggregate functions
- GROUP BY
- ORDER BY
- Date functions
- SUM and MONTH functions

## 5. Project Files
- **AdventureWorks2012_Queries.sql** – Contains the SQL queries performed in this project.
- **SQL_Project_Screenshots.pdf** – Contains screenshots of SQL queries and their outputs.

## 6. Learning Outcomes
- Improved practical understanding of SQL.
- Gained experience working with relational databases.
- Practised retrieving, filtering, grouping and analysing business data.
